# Stock-Tracker
A simple stock tracker that calculates total investment based on user input stock names and quantities using a predefined dictionary of stock prices. It displays the total investment value and portfolio summary. Optionally, results can be saved in TXT or CSV files. It uses loops, dictionaries, arithmetic, and file handling.
